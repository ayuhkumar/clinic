# Aava Skin — Frontend Practice Project

A React + Vite frontend recreation inspired by the supplied Aava Skin practice website.

## Run

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Build

```bash
npm run build
npm run preview
```

## Pages

- `/` Home
- `/signin` Sign in / Sign up
- `/doctor` Doctor
- `/payment` Payment
- `/appointment` Appointment
- `/pricing` Pricing
- `/treatments` Treatments
- `/specialized` Specialized Care
- `/help` Help
- `/contact` Contact

## Important

This is a frontend practice project. Authentication, payments, appointments, maps and contact actions are simulated or placeholder UI. Replace placeholder doctor/contact/pricing information with verified information before any real deployment.

The project uses React + Vite. Vite's current documentation recommends `npm create vite@latest` for scaffolding and documents the React template/build workflow. React's documentation also describes Vite as an option for building a React app from scratch.
